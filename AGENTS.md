# AI organic creator project

Use this folder as the working project. Explain things simply, at about sixth-grade level. Define unfamiliar terms. Be direct and carry authorized work through to the requested deliverable.

Before business, research or creative work, read `context/BUSINESS.txt` and `context/CREATIVE-RULES.txt`. Then read `setup/CREATOR-SETUP.txt`, the relevant product brief, `context/WORKFLOW-MAP.txt`, and only the matching workflow and lessons. Do not load every file on every turn.

Current explicit user instructions override saved defaults. Owner-stated facts, observed evidence, assistant suggestions and unknowns must stay distinct. Historical approvals are examples, not current permission to spend or publish.

Core production defaults: vertical 9:16; video 720p; new clips 4–7 seconds unless instructed otherwise; reference remakes follow source/task duration. Nano Banana image default is two images at 2K, except where the current task specifies another count. Verify current model support. One video generation per request unless the user explicitly requests more; no automatic paid or free video quality retries, edits or duplicate submissions.

Aim for ordinary iPhone footage, natural skin and light, believable movement and exact product details. Inspect outputs; prompt wording is not proof of success. Read the workflow-specific text, audio and reference rules. In visual-hook still remakes, inspect the source screenshot locally and describe it in words; do not upload that screenshot as a generation reference.

For media creation, execute through connected tools when requested and available. A prompt-only request means prompt-only. Verify the creator's assigned media account before generation; do not assume the original owner's account or approvals transfer. Use accessible files directly. Ask only for information or approval actually missing; do not add repeat gates for authorized ordinary steps.

Save briefs, exact prompts, reference roles, settings, job IDs, outputs, review limits and feedback under `projects/<product>/<date-task>/`. Check job status before any resubmission after an uncertain response. Do not claim you watched or heard media from metadata or still frames alone.

Record natural praise and criticism with exact asset, date, source and stated reason in that project's feedback record and `knowledge/feedback.jsonl`. Never invent a reason for praise or promote one example into a universal rule. Add durable confirmed lessons to `knowledge/LESSONS.txt`; keep task exceptions local. Claim a save only after it succeeds.

Do not copy credentials into this folder. Posting, subscriptions, account changes and outreach need their own task authorization. If tools or files are unavailable, state the exact limitation and complete useful independent work. This folder does not install automations or guarantee recall outside this project.
